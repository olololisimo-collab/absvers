# absvers — Интернет-магазин модульных локеров и шкафов из АБС-пластика

Полнофункциональный проект интернет-магазина локеров из ударопрочного АБС-пластика для компании **absvers**.

## 🚀 Стек технологий
- **Фреймворк:** Next.js (App Router, React, TypeScript)
- **Стилизация:** Tailwind CSS, Lucide Icons
- **База данных и ORM:** PostgreSQL / Supabase, Prisma ORM
- **Оптимизация:** Автоматический ресайз и сжатие в WebP/AVIF (Next/Image, Sharp)
- **Деплой:** Vercel

## 📦 Комплектация проекта
1. **Интерактивный конфигуратор шкафов (`LockerConfigurator.tsx`):**
   - Расчет и модульное комбинирование секций линейки **Т-382 (XXL / L / M)**
   - Подбор замковых систем (механические, кодовые, электронные RFID/PIN)
   - Конфигурация цветов фасадов (Серый, Синий, Зелёный, Красный, Жёлтый)
   - Расчет сметы с НДС 20% и формирование коммерческого предложения (PDF / Печать)
2. **Панель администратора (`AdminDashboard.tsx` & `AdminOrdersPanel.tsx`):**
   - Управление каталогом товаров, остатками на складе и ценами
   - Обработка заказов и смена статусов
   - Редактирование характеристик и загрузка изображений без перезагрузки страницы (Optimistic UI)
3. **Схема базы данных (`prisma_schema_example.prisma`):**
   - Модели `User`, `Product`, `ProductVariant`, `Order`, `OrderItem`, `Configuration`
4. **Защищенные API-маршруты (`protected_api_route_example.ts`):**
   - RBAC-авторизация (ADMIN / MANAGER / USER)
   - Серверные эндпоинты для оформления заказов и генерации счетов
5. **Медиа и 3D-рендеры студийного качества:**
   - Высококачественные рендеры модулей Т-382XXL, Т-382L, Т-382M
   - Баннеры интерьеров раздевалок (спортзалы, детсады, смарт-офисы)
6. **Полная техническая документация и промты (`promt_magazin_abs_lokery.md`, `.docx`)**
